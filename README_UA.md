# DefenderKiller
<strong>DefenderKiller</strong> (сокр. <strong>DK</strong>) - потужна утиліта для видалення/відновлення Windows Defender (Захисник Windows).

> [!IMPORTANT]
> На форумі Win 10 Tweaker шукали актуальну версію DefenderKiller та знайшли цей репозиторій, щоб не було питань пишу тут одразу: Так, він відноситься до оригінального DefenderKiller від Vlado. Це продовження оригінального проекту, ви можете спокійно скачати будь-яку версію без нових правок (15.4, 16.0), куди я взагалі не ліз. Якщо вас щось бентежить, сміливо використовуйте їх.
> 
> До речі кажучи, дякую всім користувачам за активність, мені дуже приємно)
>

> [!TIP]
> DK надає користувачам потужний функціонал, але не несе відповідальності за ваші дії, будь ласка, будьте обережнішими при виконанні будь-яких дій через утиліту.
> 
> Недосвідченим користувачам рекомендується переглянути навчальні відео на Youtube [посилання](https://youtu.be/telq3iBkybk)

> [!WARNING]
> DK має підтримку операційних систем Windows 10/11 64-біт, але не підтримує 32-бітові OC,
> а, починаючи з версії DK 16.0, не підтримує і Windows 7. (У майбутньому повернеться підтримка старих OC).
>

### Можливості DefenderKiller 
- Видалити Windows Defender
- Створити копію (бекап) Windows Defender 
- Перевірити стан папок та файлів
- Відновити захисник із копії (бекапу)
- Видалити Безпека Windows (Іконка у пуску) (Може не працювати на 26H2)
- Сховати Розділ Безпека в Параметрах
- Вимкнути VBS (Безпека на основі віртуалізації)
- Видалити папки Захисника зі сховища WinSxS
- Вимкнення / Увімкнення Брандмауера Windows Defender 
- Вимкнення/Увімкнення UAC (Контроль облікових записів)

### Плани по DefenderKiller 
- Додати пункт про Meltdown, Spectre, Downfall
- Поліпшити інтерфейс, провести інше сортування
- Додати підтримку старих OC 
- Виправити баг у пункті "Видалити Безпеку Windows (Іконка в пуску) (Може не працювати на 26H2)"
- Виправити баг у пункті "Видалити Windows Defender"
- Додати пункт про плашку про небезпечні файли з інтернету
- Додати іконку DK
- Додати інші мови
- Провести оптимізацію
- бла бла бла

> [!IMPORTANT]
> Не всі функції з плану можуть бути додані через банальну лінощі або обмеження з боку Windows,
> але принаймні постараюся їх реалізувати.
>
